# Data Analyst Onboarding Guide

## Required Training (First 14 Days)
- Security Awareness Training (all employees)
- Data Platform Fundamentals (covers the data warehouse, Tableau, and internal query tools)
- Data Governance & PII Handling training (mandatory before accessing production data)

## Systems & Access Provisioned Automatically
Snowflake (read access to team schemas), Tableau, dbt Cloud (read access), Confluence, internal Metrics Catalog.

## 30-Day Milestones
- Complete Data Platform Fundamentals and Data Governance training.
- Reproduce one existing dashboard from source data to understand the data model.
- Meet with manager, data engineering partner, and key business stakeholders.

## 60-Day Milestones
- Deliver first independent analysis or dashboard for a stakeholder team.
- Get read/write access to at least one team dbt project after passing SQL style review.

## 90-Day Milestones
- Own a recurring reporting deliverable (weekly/monthly business review metrics).
- Complete 90-day review with manager against these milestones.
- Present findings from an independent analysis to the broader team.

## Recommended Learning Path
1. "SQL for Analytics" internal course (if not already proficient)
2. "Data Storytelling & Visualization Best Practices" workshop
3. Team-specific data model deep dive with data engineering partner
4. Tableau advanced techniques (optional, self-paced)
