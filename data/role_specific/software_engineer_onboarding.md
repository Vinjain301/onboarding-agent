# Software Engineer Onboarding Guide

## Required Training (First 14 Days)
- Security Awareness Training (all employees)
- Engineering Onboarding Bootcamp (2-day live session, covers architecture, CI/CD, code review standards)
- Git & Code Review Standards workshop
- Production Access & On-Call Basics (required before joining any on-call rotation)

## Systems & Access Provisioned Automatically
GitHub (org member), Jira, Confluence, AWS sandbox account, PagerDuty (read-only until on-call training complete), Datadog.

## 30-Day Milestones
- Complete engineering bootcamp and local dev environment setup.
- Ship first small pull request (typically a bug fix or small feature) with a peer reviewer.
- Meet with manager and each immediate teammate (1:1 intros).
- Complete Security Awareness Training and Git & Code Review workshop.

## 60-Day Milestones
- Own a medium-complexity ticket end-to-end (design, implementation, tests, deploy).
- Participate in on-call shadow shift.
- Present a "what I've learned" lightning talk at team sync (optional but encouraged).

## 90-Day Milestones
- Independently own a project component or service area.
- Join the on-call rotation (after Production Access training).
- Complete 90-day review with manager against these milestones.

## Recommended Learning Path
1. Internal "Engineering Foundations" course (Learning system, ~3 hours)
2. Language/framework-specific deep dive matching your team's stack (e.g., backend services in Go, frontend in React)
3. "Effective Code Review" internal workshop
4. Team-specific architecture deep dive, scheduled by your manager in week 2
